## 🍎 macOS Commands

> Works in **Terminal.app** or any shell (Zsh, Bash, Fish). macOS doesn’t include `fallocate`, but `mkfile` and `truncate` work perfectly.

### Command

```bash
mkfile 100m test.bin
```
> Generates a `100Mb` file named test.bin
```bash
mkfile 1g test.bin
```
> Generates a `1Gb` file named test.bin
```bash
mkfile 10g test.bin
```
> Generates a `10Gb` file named test.bin
